# ZEUS IA Autônomo

Agente heurístico local em Python, com Biblioteca Oficial ZEUS, memória SQLite, auditoria encadeada e aplicativo Android compilado por GitHub Actions.

## Estado

- Modelo heurístico local: integrado
- Biblioteca Oficial ZEUS: local
- Memória: SQLite local
- Auditoria: Event Log + SHA-256
- Android: Kivy/Buildozer
- Dependência operacional do ChatGPT: nenhuma
